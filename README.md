# FreshBite Food UI

A colorful, responsive food-ordering landing page built with Next.js and React.
It is a frontend-only project with no backend or database.

## Features

- Responsive desktop and mobile layout
- Menu category filters
- Interactive add-to-bag counter
- Hero, menu, promotion, story, and contact sections
- Static export for straightforward hosting

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000` in your browser.

## Production build

```bash
pnpm build
```

The static, hosting-ready output is generated in `dist/`.
